Case writer · the only component that writes

InvestigationCase + EvidenceRequest + ActionRecord, with CASE_TXN, CASE_CARD, CASE_DEVICE, CASE_RULE, CASE_CITES ... edges. auto actions are executed (simulated); L1 / L2 actions wait for a human.

Bank controls

Fail closed

Graph or MCP down: the case stops, no answer is written, an older answer moves to stale/. Exit 2.

Approvals

The server maps a token to a role; the request body can't. Append-only, one decision per action.

Audit log

Hash-chained and HMAC-keyed; personal data redacted. /api/audit/verify re-checks the chain.

Case-book gate

No card may be cleared in one case and reported or blocked in another. Run before every freeze.
